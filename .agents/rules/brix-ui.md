# Brix UI

Read `docs/design.md` before changing a screen.

- Canvas `#fdfcfc`, cards `#f5f3f1`, borders `#ebe8e4`, text `#000000`, body `#777169`.
- Filled actions are black pills. Outline pills are eggshell with a stone border.
- Violet `#0447ff` and orange `#ff4704` are decoration only.
- Display type is Inter 300. Do not bold it.
- Cards are 20px, taupe, flat. The only shadow is `shadow-whisper` on the stack summary.
- No sidebar. The summary does not list skills.
